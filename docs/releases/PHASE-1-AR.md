| البند | القيمة |
|---|---|
| نوع الحزمة | **تحديث جزئي**: لا تُستخدم لإنشاء الموقع من الصفر |
| النسخة الأساسية | النسخة الحالية على Hostinger (API إصدار `2026-11-01.V95`)، سواء رُكّبت الحزمة 0 أم لا |
| التحديثات السابقة | **تشمل الحزمة 0 بالكامل**. إذا لم تركّب الحزمة 0 بعد فركّب هذه وحدها |
| تعديل قاعدة البيانات | **لا يوجد**. بيانات الكورسات تُحفظ في جدول `academy_data` الحالي بمسارات جديدة |
| أثر التحديث على البيانات الحالية | لا تُحذف ولا تُحوَّل أي بيانات. الحسابات والدروس والاشتراكات والصلاحيات تبقى كما هي |

## ما الجديد؟

### للطالب
- **قسم "كورسات مميزة لصفك"** في الرئيسية بعد تسجيل الدخول، وتختاره الإدارة وترتّبه.
- **صفحة الكورسات** (المزيد ← الكورسات):
  - بحث بالاسم أو المعلم أو المادة، وفلترة حسب المادة.
  - خيار "كورسات صفي فقط"، وتبويب "كورساتي".
- **صفحة تفاصيل الكورس** تعرض:
  - الوصف، وما سيتعلمه الطالب، ومحتوى الكورس مقسمًا إلى أقسام، والسعر، وحالة الاشتراك.
  - الفيديو التعريفي، والعناصر المتاحة كمعاينة مجانية.
- **زر "اشترك عبر واتساب"**: يفتح واتساب الإدارة برسالة جاهزة فيها اسم الكورس والمادة والصف والسعر واسم الطالب.
- **تفعيل الكورس بكود** من صفحة الكورسات أو من صفحة الكورس نفسها.
- **أيقونات تواصل احترافية** (واتساب، فيسبوك، تليجرام، يوتيوب، تيك توك) مع حركة عند التمرير واللمس.

### للمعلم
- **"كورساتي"** في القائمة (المزيد ← الكورسات): إنشاء كورس، وتعديله، وحفظه كمسودة، وإرساله للمراجعة.
- المحتوى المتاح للمعلم: دروس واختبارات وملفات من المنهج **داخل تكليفه فقط**، بالإضافة إلى فيديوهات وملفات PDF وروابط وملاحظات خاصة بالكورس.
- **تعديل كورس منشور** لا يغيّر النسخة الظاهرة للطلاب إلا بعد موافقة الإدارة، إلا إذا كانت للمعلم صلاحية النشر المباشر.
- كورسات المعلم المنشورة تظهر في **صفحته العامة**.

### للإدارة
- **"إدارة الكورسات"** (المحتوى والمناهج ← إدارة الكورسات)، وفيها:

| التبويب | ما يفعله |
|---|---|
| الكورسات | إنشاء وتعديل ونشر وإخفاء وأرشفة |
| المراجعات | الموافقة على كورسات المعلمين وتعديلاتهم، أو رفضها مع ملاحظة تصل للمعلم |
| المميزة في الرئيسية | اختيار حتى 12 كورسًا وترتيبها |
| أكواد التفعيل | إصدار أكواد بعدد مرات استخدام ومدة وصول (أيام أو مدى الحياة) وتاريخ انتهاء، مع سجل يوضح من فعّل كل كود ومتى، وإيقاف أي كود |
| المشتركون | عرض المشتركين في كل كورس، ومنح وصول يدوي بالبريد، وإلغاء الوصول |
| واتساب والرسالة | رقم واتساب الإدارة ونص الرسالة الجاهزة |

- **صلاحيتان جديدتان للمعلم** في "صلاحيات المعلمين":
  - "إنشاء الكورسات": مفعّلة افتراضيًا.
  - "نشر الكورسات وتعديلاتها مباشرة دون مراجعة": معطّلة افتراضيًا.
- **قرار "يُفتح بالخطة"** لكل كورس تتخذه الإدارة وحدها، والمعلم لا يغيّره.

### الحماية على الخادم
- محتوى الكورس (روابط الفيديو والملفات والملاحظات ومعرّفات الدروس) **لا يُرسل للمتصفح** إلا لمن له حق الوصول: مشترك فعّال، أو كورس مجاني لطالب مسجّل، أو خطة عامة تشمله إذا سمحت الإدارة بذلك.
- الدروس والاختبارات المضمّنة في كورس تُفتح للمشترك حتى عندما يكون "فرض الاشتراك" مفعّلًا، وتبقى مغلقة لغير المشتركين. إذا أُلغي الاشتراك تُغلق فورًا.
- نص الأكواد **لا يُخزَّن**؛ يُحفظ أثرها المشفّر (hash) فقط. لذلك انسخ الأكواد فور إصدارها.
- لا يستطيع الطالب أو المعلم قراءة جداول الكورسات أو الأكواد أو الاشتراكات مباشرة، ولا كتابتها.

### إصلاح إضافي
- في شاشة صلاحيات المعلمين كانت "إنشاء الحصص المباشرة" تظهر غير مفعّلة رغم أنها مسموحة افتراضيًا على الخادم، فإذا حفظت الصلاحيات تُلغى دون قصد. أصبحت تظهر كما هي فعليًا.

## خطوات التركيب (10 دقائق)

1. **نسخة احتياطية:**
   - **الملفات:** File Manager ← `public_html` ← حدّد `api` و`assets` و`v22` و`index.html` و`admin.html` و`teacher.html` و`parent.html` ← **Compress** ← احفظ الناتج باسم `backup-before-phase1.zip` وحمّله على جهازك.
   - **قاعدة البيانات:** phpMyAdmin ← Export ← Quick ← SQL.
2. فك ضغط `phase-1.zip` على جهازك. ستجد المجلدات `api` و`assets/build` و`v22` و4 ملفات HTML.
3. **ارفع ملفات PHP أولًا** إلى `public_html/api/` (وافق على الاستبدال).
4. **ثم ارفع ملفات `assets/build`** التسعة إلى `public_html/assets/build/`.
5. **ثم ارفع ملفات `v22`** إلى `public_html/v22/`.
6. **أخيرًا ارفع ملفات HTML الأربعة** إلى `public_html/` (وافق على الاستبدال).
   > الترتيب مهم: ملفات HTML آخرًا، حتى لا تطلب الصفحات ملفات لم تُرفع بعد.
7. **التخزين المؤقت:**
   - إذا كان LiteSpeed Cache أو CDN مفعّلًا: hPanel ← Website ← Cache Manager ← **Purge All**.
   - في المتصفح: اضغط Ctrl+F5 مرة واحدة.
   - الملفات المجمّعة لها أسماء جديدة، فلن تتعارض مع النسخ القديمة.

## التحقق على Hostinger

1. `https://موقعك/api/health` تعرض `"ok":true`.
2. **إدارة:** لوحة الإدارة ← المحتوى والمناهج ← **إدارة الكورسات**.
   - في "واتساب والرسالة" اكتب رقمك واحفظ.
   - أنشئ كورسًا تجريبيًا بسعر 100، وأضف فيديو بعلامة "معاينة مجانية" وملف PDF، واحفظه بحالة **منشور**.
   - من "المميزة في الرئيسية" اختره واحفظ.
3. **طالب (من الهاتف):**
   - الرئيسية تعرض "كورسات مميزة لصفك" (إذا كان صف الكورس يطابق صف الطالب).
   - افتح الكورس: الفيديو التجريبي متاح، والـ PDF مقفول 🔒.
   - زر "اشترك عبر واتساب" يفتح محادثة برقمك برسالة فيها اسم الكورس.
4. **إدارة:** من "أكواد التفعيل" أصدر كودًا واحدًا للكورس وانسخه.
5. **طالب:** أدخل الكود في صفحة الكورس، فيجب أن تظهر "اشتراكك فعّال" وتُفتح كل العناصر. جرّب الكود نفسه مرة أخرى، فيجب أن يُرفض.
6. **إدارة:** في "سجل الأكواد" يظهر الكود مستخدمًا (1/1) باسم الطالب، وفي "المشتركون" يظهر الطالب.
7. **معلم:** المزيد ← الكورسات ← كورس جديد ← إرسال للمراجعة، ثم يظهر عند الإدارة في "المراجعات".
8. احذف الكورس التجريبي بعد التحقق: إدارة الكورسات ← **أرشفة**.

## التراجع

1. فك ضغط `backup-before-phase1.zip` وارفع ملفات HTML الأربعة وملفات `api` فوق الجديدة.
2. احذف `api/v101-courses.php`. وإن لم تكن ركّبت الحزمة 0 من قبل فاحذف `api/v101-maintenance.php` أيضًا.
3. الملفات الجديدة في `assets/build` و`v22` لا تضر إذا بقيت، ويمكن حذفها.
4. بيانات الكورسات المحفوظة (`coursesV1` و`courseCodesV1` و`courseEnrollmentsV1` و`courseSettingsV1`) لا تؤثر على النسخة القديمة. إذا أعدت تركيب الحزمة لاحقًا تعود كما كانت.

## ما تم اختباره فعليًا

- **بيئة الاختبار:** PHP 8.3 وMariaDB 10.11 محمّلة بهيكل قاعدتك، ومتصفح Chromium على مقاس هاتف (390px) وكمبيوتر (1366px).
- **59 اختبارًا آليًا للخادم**، كلها نجحت. شملت:
  - الصلاحيات لكل دور، ومنع القراءة والكتابة المباشرة لبيانات الكورسات.
  - إخفاء المحتوى المقفول، والمعاينة المجانية.
  - الأكواد: الاستخدام المتكرر، والإيقاف، والانتهاء، والتمديد، والسجل.
  - فتح الدروس المضمّنة مع فرض الاشتراك، وإغلاقها بعد إلغاء الاشتراك.
  - مراجعة تعديلات المعلم، وصلاحية النشر المباشر، والكورس المجاني، والفتح بالخطة، والتصفية حسب صف الطالب.
- **22 اختبارًا في المتصفح**، كلها نجحت. غطّت:
  - المعلم ينشئ كورسًا من الهاتف، والإدارة توافق وتصدر كودًا وتحفظ رقم واتساب.
  - رابط واتساب ونص الرسالة.
  - الطالب يفعّل الكود من الهاتف فيُفتح المحتوى، ويفتح درسًا من الكورس ثم يرجع.
  - البحث والتبويبات، والتنقل بلوحة المفاتيح، والوضع الليلي.
- **انحدار:** اختبارات الحزمة 0 (17/17)، والبوابات الأربع بلا أخطاء JavaScript ولا تمرير أفقي، وإرسال الاختبار يعمل كما كان.
- **لم يُختبر:** خادم Hostinger نفسه، وتشغيل فيديو يوتيوب فعليًا (بيئة الاختبار بلا إنترنت عام)، وفتح تطبيق واتساب على هاتف حقيقي. خطوات التحقق أعلاه تغطي هذه النقاط.
