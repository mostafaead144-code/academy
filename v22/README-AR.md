# V22 — واجهات V20 المتصلة بـ Hostinger API

هذه نسخة إعادة بناء للواجهات الرئيسية على قاعدة الأكاديمية الفعلية، وليست نسخة المعاينة القديمة.

أهم الصفحات:
- index.html: الزائر، الاستكشاف، الطالب، إنشاء حساب الطالب وتسجيل الدخول، الدروس والاختبارات ونتائجها
- admin.html: دخول المدير، إضافة المعلمين وتكليفهم، إضافة الدروس والاختبارات، مراجعة طلبات المعلمين ونشرها
- teacher.html: دخول المعلم، إرسال درس أو اختبار للموافقة، عرض طلباته
- parent.html: تسجيل ولي الأمر وربطه بكود من حساب الطالب ومتابعة الدرجات

## حدود الإصدار
- يلزم خادم PHP + MySQL وإعدادات Hostinger الأصلية. صفحات HTML وحدها لا توفر تسجيل دخول أو قاعدة بيانات.
- لم تُختبر قاعدة البيانات الحية في بيئة التطوير؛ يجب اختبار كل دور على نسخة اختبار قبل النشر النهائي.
- تم تبسيط الميزات القديمة (التحديات، الفصول المباشرة، التراسل والمجتمع) في هذه الواجهة. ملفات API الأصلية موجودة.
- ينشئ المدير المعلم ويُسند إليه مادة وصفًا. يسمح الخادم بالنشر والمراجعة بحسب الصلاحيات؛ لا توجد محاكاة لصلاحيات النشر.
- لا يربط ولي الأمر طالبًا إلا عبر كود من الطالب؛ ربط الهاتف وحده غير مستخدم في الواجهة الجديدة.
- نتيجة اختبار V22 تسجل داخل studentProfilesV3/{uid}/quizResultsV22، ولا تحل محل إحصاءات النظام القديم.
- لا تعرض النسخة أرقامًا وملفات معلمين تجريبية؛ إن لم توجد بيانات حقيقية تظهر حالات فارغة.
- إدارة اختبارات الإدارة والمعلم بنموذج إدخال JSON، وهي مرحلة أساسية قابلة للتطوير إلى محرر مرئي لاحقًا.
- ملفات PHP القديمة محفوظة دون تعديلات؛ الإعدادات السرية config.local.php غير موجودة في الحزمة التوزيعية. احتفظ بالإعدادات الموجودة على استضافتك.
